# Tessra 1.2.7

## A shorter demo that shows streaming

The README and Marketplace demo is a new 20-second cut recorded in VS Code with the installed extension. It sends a request with `{{variable}}` autocomplete, switches from `local` to `staging`, runs a collection and reruns only the failed request, and receives a server-sent event stream. The looping animated preview and the full video with sound stay in the same places.

No extension code changes.
